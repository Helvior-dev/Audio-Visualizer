# Audio Visualizer (Legacy Version)

A real-time, GPU-accelerated audio visualization suite for Windows written in Python. This legacy version provides a set of modular visualizers for monitoring audio playback directly from system output (WASAPI Loopback).

## Archived Modules
- Loudness Meter (LUFS & Peak)
- Oscilloscope
- Spectrum Analyzer
- Spectrogram (Waterfall)
- Stereometer (Vectorscope)

*Note: Please refer to the root directory for the new modular 6-module suite.*
